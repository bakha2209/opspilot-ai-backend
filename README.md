## Project setup

# OpsPilot AI Backend

OpsPilot AI is a multi-tenant B2B SaaS backend for inventory and reorder operations, enhanced with an AI operations copilot.

## Tech Stack

- NestJS
- TypeScript
- PostgreSQL
- TypeORM
- Redis
- RabbitMQ
- WebSocket
- OpenAI API
- Swagger
- Docker

## Current Status

This project is currently in active development.

### Completed

- NestJS backend setup
- Environment-based configuration
- PostgreSQL Docker setup
- Redis Docker setup
- RabbitMQ Docker setup
- Swagger configuration
- Health check API

### Planned Features

- Multi-tenant company structure
- JWT authentication
- Role-based access control
- Product and inventory management
- Stock movement tracking
- Reorder workflow
- RabbitMQ event-driven processing
- WebSocket real-time notifications
- OpenAI-powered operations copilot
- Audit logging
- Hyperledger Fabric integration

## Local Development

### 1. Install dependencies

```bash
npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

## Deployment

When you're ready to deploy your NestJS application to production, there are some key steps you can take to ensure it runs as efficiently as possible. Check out the [deployment documentation](https://docs.nestjs.com/deployment) for more information.

If you are looking for a cloud-based platform to deploy your NestJS application, check out [Mau](https://mau.nestjs.com), our official platform for deploying NestJS applications on AWS. Mau makes deployment straightforward and fast, requiring just a few simple steps:

```bash
$ npm install -g @nestjs/mau
$ mau deploy
```

With Mau, you can deploy your application in just a few clicks, allowing you to focus on building features rather than managing infrastructure.

## Architecture Goal
The project is designed as a modular monolith with event-driven internals.
The first version focuses on inventory and reorder operations. Later stages will introduce AI workflow automation, real-time alerts, and blockchain-based audit verification.
